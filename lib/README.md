# MM assets: общая библиотека для каруселей и рилсов

Одна папка на все генераторы: карусели (`~/Documents/mm-carousels/lib` → сюда) и рилсы (`MM/reels/_assets` → сюда). Каждый файл описан в `manifest.json`: id, путь, тип, теги, лицензия, источник.

| Папка | Что | Сколько | Лицензия |
|---|---|---|---|
| `memoji/` | мемоджи Умара: think, oops, laptop, wink, swear | 5 | личные, только для MM и канала ИИшница |
| `stickers/fluent-3d/` | 3D-эмодзи Microsoft Fluent: эмоции, руки, предметы | 83 | MIT (`LICENSE`), атрибуция не нужна |
| `stickers/3dicons/` | 3D-иконки 3dicons | 69 | CC0 |

Превью: `preview-stickers.jpg`, `preview-photos.jpg`.

## Как брать

- Карусели (`mm-reels`): в спеке пишется id из манифеста: `"sticker": "fluent/fire"`, `"photo": "photo/man-panic-laptop"`, `"visual": {"kind": "sticker", "id": "fluent/rocket"}`. Сборщик копирует файл в выпуск и пишет лицензию в `meta.json`.
- Рилсы: `reels/_assets/<file>` (симлинк), путь из поля `file`.

## Мемы

Готовые мем-шаблоны из интернета не храним: это чужие фото с неизвестными правами. Мемы собираем сами из своих ассетов. Форматы в шаблоне карусели `mm-reels`, kind `meme`:
- `expect`: ожидание / реальность на мемоджи;
- `vs`: я / нейросеть (мемоджи против 3D-робота);
- `photo`: фото из `photos/unsplash` + капс-подпись сверху.

## Правила

- Новые файлы добавлять вместе с источником и лицензией, потом пересобрать `manifest.json`.
- Скачивание новых фото и рендеров только с согласия Умара.
- Не класть сюда: шрифты SF / New York, SF Symbols, эмодзи Apple, Twemoji, мем-шаблоны из интернета.
